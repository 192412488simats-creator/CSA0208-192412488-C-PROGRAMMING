### Assignment Description
This assignment focuses on applying C programming concepts such as operator precedence, associativity, short-circuit evaluation, bitwise operators, decision-making statements, loops, and algorithm optimization. The programs are implemented, executed, tested, and validated using GCC.

### Question Details

**Q1 – Precedence, Associativity and Discount Calculation**

Demonstrates how operator precedence and associativity affect arithmetic expressions and corrects errors in pharmacy discount and tax calculations.

**Q2 – Short-Circuit Evaluation in Railway Concession Eligibility**

Implements short-circuit logical operators to check passenger eligibility for railway concessions and compares condition evaluations.

**Q3 – Device-Status Register Using Bitwise Operators**

Uses bitwise operators to set, clear, and check device-status bits, such as air conditioning and pump status.

**Q4 – University Grade and Scholarship Classifier**

Classifies students based on marks and determines scholarship eligibility based on family income using an else-if ladder and switch statement.

**Q5 – Prime Number Checking Using Different Loops**

Implements prime-number checking using for, while, and do-while loops and compares their efficiency by counting divisor checks.

**Q6 – Loan Repayment Schedule and Interest Calculation**

Calculates monthly loan interest, repayment amounts, and outstanding balance until the loan is fully repaid.

**Q7 – Optimized Prime Number Checking Using Odd Divisors**

Optimizes the prime-number checking algorithm by skipping even divisors and compares its efficiency with the original method.
